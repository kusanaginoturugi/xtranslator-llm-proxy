# 辞書なしで固有名詞はどこまで当たるか

[README の Quality 節](../../../README.md#quality-辞書なし)の比較で、ローカル（`gemma-4-12b-it-qat-imatrix`）は
`Ulfric Stormcloak` を「ウルフリック・ストームクローク」と公式訳どおりに訳した。辞書なしなのになぜ当たるのか、を見た。

## 結論

モデルが公式訳を覚えているわけではない。公式訳がほぼ音写どおりの名前は当たり、ひねった公式訳の名前は外す。
これはローカルも Cloudflare（`@cf/google/gemma-4-26b-a4b-it`）も同じで、確認できた 9 か所のうち公式訳どおりはローカル 2、Cloudflare 3 だった。
公式訳を揃えるのは辞書の役目で、プロキシが辞書スナップショットから用語と類似例文を渡しているのはこのため。

## 読み方

- 当たったのは、英語の読みをそのままカタカナにすれば公式訳になる名前（ウルフリック、ストームクローク）と、直訳すれば公式訳になる名前（盗賊ギルド）。
- 外したのは、公式訳が意訳の名前（同胞団、闇の一党）と、音写の仕方が独特な名前（サルモール、マルカルス、ハイ・フロスガー）。
- Cloudflare はハイ・フロスガーとマルカルスを当てていて、こちらの方が少し知っている可能性がある。ただ件数が少なく、差は言えない。
- Cloudflare の「ウルフレリック」は知識不足というより生成中の崩れに見える（同じ回でタイ文字の混入もあった）。
- プロンプトにはゲーム名（`XTRANSLATOR_GAME_TITLE`）を入れていて、Skyrim の知識を引き出しやすくはなっている。両方に同じ条件。
